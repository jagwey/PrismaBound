# PRISMBOUND shared contract

Godot 4.7.2, 640x360. Root builds menu/save/story/audio; independent modules below. Use typed GDScript, avoid warning-as-error inferred Variant pitfalls. Programmatic original pixel visuals are explicitly temporary art.

## Core (scripts/player.gd, scripts/projectile.gd, scripts/combat.gd)
Player extends CharacterBody2D, class_name PrismPlayer. World coordinates: floor top y=300; avatar approximately 20x32, origin feet; starts (80,280). Group `player`. Public hp/max_hp (100), stamina/max_stamina, energy, shards, mode integer 0..5, unlocked_modes Array[int], stored attacks. aim Vector2. Methods take_damage(amount:float, from:Vector2), heal(), configure_progress(region:int, upgrades:int), release_stored(), add_shards(amount:int). Signals died, stats_changed. Actions move_left/right, jump, dash, guard, reflect, bash, mode, absorb, release, interact, pause, aim_left/right/up/down via InputMap set by root. Player can use get_parent() as world Node2D; enemies in group `enemies`. Enemy API take_damage(amount:float, from:Vector2, perfect:bool=false), enemy position is center.
Projectile extends Node2D, class_name PrismProjectile. Public velocity Vector2, damage float, team int (0 hostile,1 player), kind String (normal/heavy/arc/spread/beam/shockwave/dark/explosive), element String, lifetime float, reflection_count int, owner_actor Node. Static spawn(parent:Node, pos:Vector2, vel:Vector2, damage:float=12, kind:String="normal", element:String="neutral", team:int=0) -> PrismProjectile. Normal reflection uses bounce(normal) with genuine facing test and perfect window. Player method handle_projectile(projectile) -> bool returns handled when blocking/reflect/absorb. Projectile handles enemy/player distance collisions, world bounds, repeated-hit prevention. World method on_projectile_environment(p:Node)->bool optionally handles puzzle targets; return true means consume projectile. Use has_method for optional world hook.

## Enemies (scripts/enemy.gd)
class_name PrismEnemy extends Node2D. Public archetype int 0..6, region int 0..4, is_boss bool, hp/max_hp float, display_name String. configure(type:int, area:int, boss:bool=false) called BEFORE add_child. Enemy origin at center (floor enemy pos.y=280). Signal defeated(enemy) before queue_free. Methods take_damage(amount:float, from:Vector2, perfect:bool=false). All projectile spawn via load/preload script static spawn contract above. Groups enemies and bosses. Player located get_tree().get_first_node_in_group("player"). Root world hooks award shards from defeated signal, handles boss progression. No root/autoload dependency. Boss gets at least two phases unique region patterns, readable telegraph. No damage while menus pause tree.

## World (scripts/world.gd, data/regions.json)
class_name PrismWorld extends Node2D. Public region int, player PrismPlayer, boss Node, checkpoint Vector2. configure(area:int, progress:Dictionary) BEFORE add_child. Builds geometry (StaticBody2D layer 1), platforms/parallax/environment, player (layer2 mask1), enemies, checkpoint, mirror puzzle and locked boss entrance. signals region_completed(area:int), checkpoint_reached(area:int), story_requested(key:String), player_died. Methods restart_checkpoint(), on_projectile_environment(p:Node)->bool. Core/enemies loaded via preload; agent can create TEMP STUBS for validation only, never commit stubs. Root camera/HUD? World supplies Camera2D following player; width ~2400 minimum, 3 encounter sections and boss arena. Camera limits y=0..360. World exposes objective:String and puzzle_solved:bool. E interacts near checkpoint and exit; boss defeat opens exit. Load data/regions.json with name, boss, palette/background/tint, story, reward. Root handles upgrades and save via progress dictionary keys upgrades:int, shards:int, unlocked:int (highest region reached), cleared:Array, flags:Dictionary.

## Root integration
Main scene owns current world, CanvasLayer HUD/menu/dialogue; pause tree for dialogs. Persist via user:// with validation and backup. Audio generated local original PCM assets or procedural synthesis, marked temporary.
